# MVP LOCK
# This file is the law. Nothing gets added without updating this file first.

---

## The Mission

> Systematically discover real pain from Telegram community owners.

Not selling. Not automating. Not AI.
Discovery.

---

## Included In MVP

- [x] Accounts — manage Telegram user accounts for outreach
- [x] Campaigns — containers for outreach operations
- [x] Templates — random message selection per campaign
- [x] Targets — import usernames (paste or TXT), track status
- [x] Scheduler — send messages with human-like random delays
- [x] Pause / Resume / Stop campaign
- [x] Reply tracking — detect when someone replies, notify you
- [x] Pain Tags — reusable categories, assigned per target
- [x] Notes — one free-text field per target
- [x] Export Conversations — pull live from Telegram via Telethon

---

## Explicitly Excluded (Forever for V1)

- [ ] AI replies
- [ ] Auto-replies of any kind
- [ ] Lead scoring
- [ ] Scraping / finding targets
- [ ] Account rotation / health scoring
- [ ] Analytics dashboards
- [ ] Global template library
- [ ] Auto classification
- [ ] Auto summaries
- [ ] Multi-user / SaaS
- [ ] Billing / permissions
- [ ] Retry engine
- [ ] Conversation history storage (Telegram owns this)

---

## The Filter

Before adding ANY feature, ask:

> **Does this help us discover pain faster?**

Yes → consider it.
No → BACKLOG.md.
